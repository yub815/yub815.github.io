개인정보처리방침

시행일: 2026년 11월 3일

1. 수집하는 정보

OBS 드라이브 업로더(이하 "앱")는 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 앱은 사용자가 지정한 PC 폴더의 녹화 파일을 Google 드라이브에 업로드하는 기능만 수행합니다.

2. Google 사용자 데이터 사용

앱은 Google Drive API의 drive.file 권한만 사용하며, 앱이 직접 만든 폴더와 앱이 업로드한 파일에만 접근합니다. 드라이브의 다른 파일은 읽거나 수정하지 않습니다. Google 사용자 데이터는 업로드 목적 외에 사용하거나 제3자에게 제공, 판매하지 않습니다.

앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

3. 저장되는 정보

앱은 설정값(녹화 폴더 경로 등), 업로드 기록, 오류 로그를 사용자 PC에만 저장합니다. 이 정보는 앱을 삭제하거나 해당 폴더를 지우면 삭제됩니다.

4. 접근 권한 해제

계정 소유자는 언제든지 Google 계정 권한 페이지에서 앱의 접근을 해제할 수 있습니다.
